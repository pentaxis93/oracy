`client/` contains Oracy's Flutter application. Build the app with `cd client && flutter pub get`. This code is imported as a snapshot from the Python-era repository and will be adapted in later work to the contract in [`spec/api-contract.md`](../spec/api-contract.md). The checked-in web runtime assets such as `web/drift_worker.dart.js`, `web/drift_worker.dart.js.map`, and `web/sqlite3.wasm` are intentional generated or vendored snapshot artifacts and should not be hand-edited.
